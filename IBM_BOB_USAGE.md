IBM Bob was used as an AI-powered development assistant throughout the development of the AI Career Copilot project. It helped us understand the project requirements, plan the application structure, develop features, debug errors, and improve the deployment process.

The project was developed as a full-stack monorepo containing two main parts:

1. Frontend:
   - Next.js
   - React
   - JavaScript/TypeScript
   - HTML and CSS

2. Backend:
   - Node.js
   - Express.js
   - MongoDB Atlas
   - Mongoose
   - JWT authentication

IBM Bob was used during the planning stage to break the project into smaller modules such as user authentication, career guidance, dashboard features, backend APIs, database connectivity, and deployment.

During development, IBM Bob helped with:
- Understanding the existing project structure
- Creating and improving frontend components
- Developing backend API logic
- Connecting the Express backend with MongoDB Atlas
- Implementing signup and login functionality
- Understanding JWT secret generation and authentication
- Fixing MongoDB connection issues
- Removing deprecated MongoDB connection options
- Understanding environment variables
- Debugging deployment errors
- Preparing the project for Render and Vercel deployment

IBM Bob also helped us understand the difference between frontend and backend deployment. The Next.js frontend was deployed on Vercel, while the Express and MongoDB backend was deployed on Render. It guided us in configuring environment variables such as MONGODB_URI, JWT_SECRET, NODE_ENV, DEMO_MODE, CLIENT_URL, and NEXT_PUBLIC_API_URL.

The development workflow followed an iterative process. We first created the application structure, then developed and tested individual features. When errors occurred, IBM Bob helped us understand the error messages and suggested practical fixes. We tested the backend using its health-check API and confirmed that MongoDB Atlas was connected successfully.

IBM Bob was also used to improve our understanding of deployment logs, API URLs, CORS configuration, GitHub integration, and environment variable setup. This helped us move the project from local development to a publicly accessible application.

Overall, IBM Bob supported the project from idea development to implementation, debugging, testing, and deployment. It helped us learn full-stack development concepts in a beginner-friendly way and made the development process faster and more organized.
